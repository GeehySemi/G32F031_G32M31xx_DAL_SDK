&par Example Description

This example shows how to use the comparator.
COMP non-inverting input connect to PA7.
And COMP inverting input is connected to PA8.
COMP output connect to PA5.

&par Directory contents

  - COMP/COMP_Output/Source/main.c               Main program
  - COMP/COMP_Output/Source/g32f031_int.c        Interrupt handlers

&par IDE environment

  - MDK-ARM V5.40
  - EWARM V8.50.5.26295
  - ECLIPSE-EMB V4.24.0

&par Hardware and Software environment

  - This example runs on G32F031 EVB Devices.
