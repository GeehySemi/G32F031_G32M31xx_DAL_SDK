&par Example Description

This example shows how to use a DMA channel to transfer a word data buffer from
FLASH memory to embedded SRAM memory.

DMA channel1 is configured to transfer the contents of a 32-word data
buffer stored in Flash memory to the reception buffer declared in RAM.In the end,
The data of the address will displayed on serial assistant through USART.

&par Hardware Description

The USART is configured as follows:
    - TX:PA10, RX:PA11
    - BaudRate = 115200 baud
    - Word Length = 8 Bits
    - One Stop Bit
    - No parity
    - Hardware flow control disabled (RTS and CTS signals)
    - Receive and transmit enabled

&par Directory contents

  - DMA/DMA_FLASHToRAM/Source/main.c                Main program
  - DMA/DMA_FLASHToRAM/Source/g32f031_int.c         Interrupt handlers

&par IDE environment

  - MDK-ARM V5.40
  - EWARM V8.50.5.26295
  - ECLIPSE-EMB V4.24.0

&par Hardware and Software environment

  - This example runs on G32F031 EVB Devices.
