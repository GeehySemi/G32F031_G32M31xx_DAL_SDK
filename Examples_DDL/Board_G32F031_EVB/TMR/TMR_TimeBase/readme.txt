&par Example Description

This example describes how to use ATMR for toggling IO.
The IO of LED2 is configured to toggle constantly every 500ms.
The phenomenon of LED2 constantly flickered alternately.

&par Directory contents

  - TMR/TMR_TimeBase/Source/main.c               Main program
  - TMR/TMR_TimeBase/Source/g32f031_int.c        Interrupt handlers

&par IDE environment

  - MDK-ARM V5.40
  - EWARM V8.50.5.26295
  - ECLIPSE-EMB V4.24.0

&par Hardware and Software environment

  - This example runs on G32F031 EVB Devices.
